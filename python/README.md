# Python Analysis – Healthcare Claims Analytics

## Overview

This folder contains Python-based data analysis and profiling performed on the Healthcare Claims Analytics dataset.

Python was used to inspect the dataset, understand data quality, identify patterns, and prepare the data for further SQL and Power BI analysis.

## Python Tools

- Python
- Pandas
- NumPy
- Jupyter Notebook
- Matplotlib

## Analysis Performed

The Python analysis includes:

- Dataset structure and dimensions
- Column and data type inspection
- Missing-value analysis
- Duplicate-record checks
- Descriptive statistics
- Numerical data analysis
- Categorical data analysis
- Claim amount analysis
- Healthcare utilization analysis
- Data quality assessment

## Key Data Fields

The analysis works with healthcare claims information including:

- Patient ID
- Age
- Gender
- State
- Diagnosis
- Provider
- Admission Date
- Discharge Date
- Insurance Type
- Claim Amount
- Length of Stay
- Claim Status

## Python Files

### `healthcare_claims_analysis.ipynb`

Jupyter Notebook containing the interactive Python analysis and results.

### `healthcare_claims_analysis.py`

Python script version of the healthcare claims analysis.

### `data_profiling.py`

Python script used for initial data profiling and quality assessment.

## Business Value

The Python analysis provides an initial understanding of the healthcare claims dataset and helps identify data-quality issues and analytical patterns before developing SQL queries and the Power BI dashboard.

This demonstrates the ability to use Python for exploratory data analysis, data validation, and business-focused healthcare analytics.
