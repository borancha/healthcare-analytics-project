# Healthcare Claims & Patient Analytics

## Project Overview

This project analyzes healthcare patient and claims data to identify trends in healthcare utilization, medical conditions, provider activity, and claim costs.

The project demonstrates an end-to-end Business Analyst and Data Analyst workflow using SQL, Python, and Power BI.

## Business Problem

Healthcare organizations manage large amounts of patient and claims data. Without effective analysis, it can be difficult to understand what is driving healthcare utilization and costs.

The objective of this project is to analyze healthcare data and provide meaningful insights that can support business and operational decision-making.

## Business Objectives

- Analyze patient demographics and healthcare utilization.
- Identify high-cost medical conditions.
- Analyze claim costs by provider and insurance type.
- Identify monthly trends in healthcare claims.
- Analyze length of hospital stay.
- Identify patterns that may require further investigation.
- Develop an interactive Power BI dashboard for stakeholders.

## Tools & Technologies

- SQL
- Python
- Power BI
- Excel / CSV
- GitHub

## Key Business Questions

1. What is the total healthcare claim amount?
2. What is the average claim amount?
3. Which diagnoses have the highest healthcare costs?
4. Which providers generate the highest claim amounts?
5. Which age groups have the highest healthcare utilization?
6. How do claims change month over month?
7. What is the average length of stay?
8. Which insurance types account for the highest claim amounts?

## Project Workflow

The project will follow an end-to-end analytics process:

1. Business requirements gathering
2. Data understanding
3. Data cleaning
4. SQL analysis
5. Exploratory data analysis using Python
6. Data visualization
7. Power BI dashboard development
8. Business insights and recommendations
